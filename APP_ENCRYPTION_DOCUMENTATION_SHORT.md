# App Encryption Documentation

German Beach Open uses only standard encryption provided by Apple OS and third parties:

**Encryption Used:**
- HTTPS/TLS (all communications)
- Firebase (OAuth 2.0, HTTPS)
- Keychain (Apple secure storage)
- Face ID (Apple biometrics)

**Custom Encryption:** None

All encryption is standard, internationally accepted. App qualifies for App Store exemption.
